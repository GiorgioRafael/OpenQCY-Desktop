# Security policy

OpenQCY Desktop communicates with user-owned Bluetooth devices and treats all device data as untrusted input.

Please report security issues privately to the maintainer instead of opening a public issue. Do not include Bluetooth addresses, HCI captures, or other personal data in a public report.

The project does not collect telemetry, require an account, or upload device data. Firmware update and downgrade operations are outside the project scope.
