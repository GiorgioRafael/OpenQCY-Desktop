# Branding

The OpenQCY Desktop icon is an original, AI-assisted project asset. It does not reuse the QCY or Apple logo, typography, or product artwork.

Final project assets:

- `Assets/AppIcon-v2.png` — transparent master used by WinUI.
- `Assets/AppIcon-v2.ico` — multi-size Windows icon used by the executable and notification area.

The icon was generated with OpenAI's built-in image generation tool and then converted from a flat magenta chroma-key background to transparency. The production prompt was:

> Create a crisp, minimal, vector-friendly Windows app icon showing two abstract wireless earbud shapes that subtly suggest the letter Q, centered inside a deep graphite rounded-square tile. Use mint/turquoise accents and a small cool-blue highlight. Keep it legible at 16 px. Do not include text, the QCY logo, Apple assets, other trademarks, shadows, reflections, or watermarks.
